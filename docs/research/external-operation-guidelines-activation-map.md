## 1. A3 总体判断

外部操作指南属于**条件性操作治理**。A3 不新增全局常驻核心候选。

跨任务成立的“仓库权威 / 项目事实边界”“不依赖未持久化会话历史”“证据先于完成声明”等不变量已经在 A2 中单独提名；而本指南大多数规则只有在外部写、跨仓库、异步运行、媒体输入、共享资源、证据晋升、依赖 PR 或 GitHub 协作等具体条件出现时才需要。

因此最低激活模型应是：

```text
发生外部状态操作
→ 激活薄闭环入口
→ 根据实际风险继续加载对应 EO-* 条件规则
```

而不是：

```text
发生任意 GitHub / 外部操作
→ 默认加载完整外部操作指南
```

## 3. 需要 A4 重点核验的高重叠组

A3 只登记关系，不作删除结论。

### 3.1 外部操作指南 ↔ `AGENTS.md`

高重叠候选：EO-01 / EO-09、EO-02 / EO-06、EO-23、EO-24。

这些很可能包含必要的常驻薄提示，但 A4 要判断完整解释是否只需保留在一个长期权威中。

### 3.2 外部操作指南 ↔ `github-actions-verification`

高重叠候选：EO-10 / EO-11、EO-12～EO-15、EO-16～EO-18、EO-25 / EO-26。

A4 应区分“平台无关的外部操作语义”与“GitHub Actions 专项执行过程”，避免同一完整流程在指南与 Skill 中平行维护。

### 3.3 外部操作指南 ↔ `using-agentic-dev.md`

重点关系：EO-16～EO-18 ↔ UG-21；EO-22 ↔ UG-20；EO-23 ↔ UG-03；EO-24 ↔ UG-08；EO-02 / EO-06 ↔ UG-22。

其中临时证据晋升是当前最明显的跨指南完整重复候选之一，必须由 A4 判断哪一层拥有完整语义、哪一层只保留激活指针。

### 3.4 依赖 PR 拓扑

EO-19～EO-22 与最近已完成的 Stacked PR 集成拓扑安全 v1 高度相关。A4 应检查当前长期项目记录、外部操作指南与平台专项能力之间是否仍有重复维护，但不得仅因为该里程碑已完成就删除长期通用规则。

## 5. “任何外部操作都加载整份指南”的检查

当前存在两个同时成立的事实：

1. EO-01 / EO-09 的写后验证闭环广泛适用于外部写操作；
2. 媒体输入、共享资源租约、证据晋升、依赖 PR 拓扑、GitHub 执行路径等大量规则只在特殊条件下成立。

因此：

> **“外部状态可能被修改”足以触发一个很薄的外部操作闭环入口，但不足以证明应加载整份 `external-operation-guidelines.md`。**

阶段 B / C 至少应能按风险区分：

- 普通外部写：EO-01、EO-09、EO-23；
- 高影响 / 授权风险：EO-02、EO-03、EO-05、EO-06；
- 媒体 / 二进制输入：EO-08；
- 异步运行：EO-10、EO-11；
- 共享资源 / 单实例：EO-12～EO-15；
- 临时证据晋升：EO-16～EO-18；
- 依赖 PR 拓扑：EO-19～EO-22；
- GitHub 执行路径：EO-25～EO-27。

## 6. A3 结论

1. 当前源指南按语义可辨识出 **28 个激活单元候选**；数量与章节数不存在机械对应关系。
2. A3 **不新增全局常驻核心候选**；外部操作职责本身应条件激活，跨任务不变量继续使用 A2 已提名的薄核心候选。
3. 最值得后续检索评估的条件组是：普通写后验证、跨仓库授权、异步闭环、共享资源 / 租约、临时证据晋升、依赖 PR 集成拓扑和 GitHub 执行路径选择。
4. S-05 与 EO-10～EO-18 形成最直接的历史映射；S-02 / S-03 则反向证明并非所有项目治理问题都需要外部操作指南。
5. 临时证据晋升、人工 / 集成授权、写后验证、GitHub Actions 生命周期和外部协作语言是 A4 必须重点审计的跨权威重叠面。
6. 当前没有足够跨权威证据判定某个完整 EO-* 单元已经陈旧或可以直接删除；也没有证据支持按文件大小机械拆分源指南。
