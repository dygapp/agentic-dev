## 1. 分类模型

A4 使用以下分类：

- **薄摘要 / 激活指针**：高层入口只保留短不变量或指向详细权威，属于合理重复；
- **职责消费**：Skill 为独立执行自身职责而重复必要的最小边界，属于合理重复；
- **实质重复候选**：同一完整规则或过程在多个长期活跃载体中并行维护，后续应优先评估收敛；
- **范围敏感**：语义相近但项目 / 使用方 / 平台 / 阶段范围不同，当前未冲突，但若丢失范围容易误选；
- **历史证据**：项目记录或 Research 只保存形成过程和验证证据，不应被当作当前并行权威。

“出现相同关键词”不等于重复错误；真正的减法目标是消除完整规则的多点维护，而不是删除必要的入口和消费边界。

## 3. 当前最重要的减法候选

按“完整语义重复程度 × 后续漂移风险 × 已有历史证据”排序：

1. **A4-09 临时证据晋升**：三处较完整维护，是当前最明显的重复规则面；
2. **A4-08 验证触发拓扑**：使用指南与平台专项 Skill 存在接近同构的完整映射；
3. **A4-06 / A4-07 执行单元身份与就绪重入**：使用指南与任务 Skill 同时维护关键完整链路；
4. **A4-10 异步 / 共享资源 / 租约**：平台无关治理与 GitHub Actions 平台适配边界仍可进一步变薄；
5. **A4-14 项目状态摘要**：不是规则语义冲突，但多入口同步会持续制造维护成本和陈旧风险。

这些只是阶段 D 的**收敛候选**，不是 A4 立即删除清单。阶段 B / C 必须先证明更薄激活方式不会降低规则召回和行为正确性。

## 4. 不应因为“做减法”而机械删除的重复

当前证据支持继续保留以下薄重复：

- `AGENTS.md` 中的仓库权威、渐进式披露、当前证据、人工 / 集成边界等极薄核心不变量；
- README 的使用入口和少量恢复指针；
- `AGENTS.md` 的外部操作薄闭环 + 指向完整外部操作指南的链接；
- 独立 Skill 为执行自身职责所需的一行级权威 / 会话历史 / 当前证据守卫；
- `docs/project/ai-review-guidelines.md` 对使用指南“项目路线图与集成状态”规则的显式激活入口；
- 已完成项目记录中的历史目标、研究和验证证据，只要新上下文不会把它当成当前执行规则。

减法目标是减少**完整规则多点维护和无条件活动上下文**，不是追求仓库中每条概念只出现一次字符串。

## 5. 同义但不同强度 / 范围检查

### 5.1 人工与集成边界

当前没有发现真正冲突：

- `AGENTS.md` 规定 `agentic-dev` 自身的集成 / 高影响边界；
- 使用指南要求使用方遵守自己的仓库权威；
- 外部操作指南只在高影响外部操作发生时激活；
- `readiness-check` / `converge` 只在对应门禁内消费这些边界。

需要阶段 B 检索模型保留“仓库范围 / 操作类型 / 当前阶段”，否则同一句“需要人工”可能被过度激活。

### 5.2 中文表达

当前两条规则必须保持区分：

- `agentic-dev` 自身面向人的内容默认自然中文；
- 使用方项目的主导语言由使用方仓库权威决定。

二者不是强弱冲突，而是作用域不同。未来索引如果只记录“语言=中文”而丢失仓库范围，会形成错误激活。

### 5.3 项目路线图

`converge` 对项目路线图是**条件检查**；`agentic-dev` 项目 AI 复核在本仓库高影响状态变更时则是**项目级强制检查**。两者触发范围不同，当前并不矛盾。

### 5.4 执行单元身份与就绪

使用指南、`slice-work`、`readiness-check` 当前语义基本一致，没有发现一个允许“预编号即可执行”而另一个禁止的冲突。问题主要是**同一完整边界重复维护**，而不是当前已经相互矛盾。

## 6. A4 结论

1. 当前没有发现需要立即修复的跨权威阻塞冲突；
2. 发现 **5 组值得后续做减法的高价值候选**，其中证据晋升、验证触发拓扑、执行单元身份 / 重入和异步共享资源属于规则语义重复，项目状态摘要属于维护面重复；
3. `AGENTS.md` 薄核心、README 入口、Skill 独立职责守卫、项目 AI 复核激活入口等重复具有明确作用，不应机械删除；
4. 已完成里程碑项目记录应视为历史证据，而不是与当前指南并行的执行权威；
5. 当前最重要的风险不是“存在完全相反的规则”，而是**同一完整规则在多个活跃载体并行维护，未来容易发生漂移，并扩大活动上下文**；
6. 这支持继续执行“规则治理做减法”的原路线，但减法应由后续检索 / 激活评估驱动，而不是 A4 直接重写文件。
