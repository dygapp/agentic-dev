## 1. 映射字段与强度

每个候选至少记录：

- **语义职责**：当前单元约束什么；
- **权威指针**：回到源指南的稳定章节；
- **触发条件**：什么任务、风险、状态或产物出现时需要激活；
- **主要消费者**：最直接消费该规则的职责；
- **强度**：核心不变量候选 / 条件必需 / 指导默认；
- **上下文层级候选**：常驻核心 / 任务能力 / 条件规则；
- **证据锚点**：A1 已冻结的历史失效或正向证据。

其中：

- **核心不变量候选**：跨多数任务成立，后续可以评估是否进入极薄常驻核心；
- **条件必需**：触发条件成立时必须遵守，但不应无条件常驻；
- **指导默认**：提供稳定默认做法，具体载体仍由使用方权威和当前证据决定。

这些字段只是阶段 A 工作视图，不构成阶段 B 的最小检索契约。

## 2. 常驻核心候选

A2 只提名 3 个常驻核心候选。“重要”本身不是常驻理由；即使后续确认常驻，也只应保留薄不变量与发现入口。

### UG-01 — 使用方仓库权威与项目事实边界

- **语义职责**：`agentic-dev` 提供可复用方法、Skill 与使用指导；使用方仓库拥有自己的项目事实、需求、架构、代码、测试与集成策略。其他聊天、个人记忆、其他项目规则以及 `agentic-dev` 自身项目规则不能直接成为使用方事实。
- **权威指针**：§1“使用模型”；§2“开始前的知识边界”。
- **触发条件**：任何使用 `agentic-dev` 推进使用方项目的任务。
- **主要消费者**：所有使用方 Agent；项目恢复、规划、实施与复核职责。
- **强度 / 层级**：**核心不变量候选 / 常驻核心**。
- **交叉候选**：`AGENTS.md` 的仓库权威 / 知识边界；多个 Skill 的权威来源。
- **证据锚点**：Issue #33、Issue #52。

### UG-02 — 渐进式披露与禁止依赖未持久化会话历史

- **语义职责**：只加载当前任务真正需要的最小权威上下文；项目事实和表达方式从仓库恢复，不从完整旧聊天或个人记忆恢复。
- **权威指针**：§2；§5.5；§7。
- **触发条件**：新上下文、任务切换、执行单元执行或工作恢复。
- **主要消费者**：所有新上下文；`execute-unit`、`converge`、项目治理职责。
- **强度 / 层级**：**核心不变量候选 / 常驻核心**；具体恢复入口继续按任务条件加载。
- **交叉候选**：`AGENTS.md`、项目路线图恢复入口、多个 Skill 的上下文规则。
- **证据锚点**：Issue #33。

### UG-03 — 证据先于完成声明

- **语义职责**：完成声明必须由与目标状态和具体验收义务匹配的当前证据支持；实现存在、代码检查、历史结果、未运行命令或无法关联目标状态的证据均不足以替代当前完成证据。
- **权威指针**：§5.7；§5.8；§10。
- **触发条件**：准备声明执行单元完成、功能已收敛或已具备进入集成决策条件。
- **主要消费者**：`execute-unit`、`converge`、AI / 人工复核、验证职责。
- **强度 / 层级**：**核心不变量候选 / 常驻核心**；证据类型、平台触发、复用与晋升等细节继续条件加载。
- **交叉候选**：`AGENTS.md` 的当前证据、`execute-unit`、`converge`、外部操作指南、`github-actions-verification`。
- **证据锚点**：Issue #52 的最终目标提交重新取得当前 CI / Review Environment 证据。

## 6. A4 必须继续核验的高重叠组

A2 只登记交叉关系，不在本阶段决定删除或合并。

### 6.1 使用指南 ↔ Skill

优先检查：

- UG-11 ↔ `clarify-intent` / `specify`；
- UG-12 ↔ `specify`；
- UG-13 ↔ `technical-plan`；
- UG-14 / UG-15 ↔ `slice-work` / `readiness-check`；

- UG-18～UG-21 ↔ `execute-unit` / `github-actions-verification`；

A4 需要区分：

1. 使用指南是否只是任务发现 / 激活入口；
2. Skill 是否拥有完整执行过程；
3. 是否存在同一行为规则在两处以近似同样强度完整维护；
4. 后续是否可以让唯一职责层保存完整语义，而使用指南只保留条件指针。

### 6.2 使用指南 ↔ 项目入口

优先检查：

- UG-01 / UG-02 ↔ `AGENTS.md`；

## 9. A2 结论

1. `using-agentic-dev.md` 当前可以按语义辨识出 **27 个规则激活单元候选**；文件大小、章节数和最终激活单元数量没有一一对应关系。
