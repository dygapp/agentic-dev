# 语言与表达规范

`agentic-dev` 面向人的内容默认使用自然、完整、连续的中文。

## 精确对象保持原样

Skill 名、文件名、路径、branch、commit SHA、Issue / PR 编号、代码标识符、配置键、API / CLI、命令、协议值，以及 `PASS`、`FAIL`、`READY`、`BLOCKED` 等稳定状态可以保持原文。外部产品、框架、协议和标准的正式名称在翻译会损害识别时也保持原样。

对象本身保持原样，不代表周围叙述也切换成英文。

## 概念身份不因润色改变

语言整理只能改变表达，不能合并不同职责或改变正式身份。例如技术规划不等于具体执行单元，`Ready to Integrate` 不等于 merge 授权。

已有稳定中文表达时沿用现有表达，不为了术语感机械制造中英双写或新的同义词。Consumer 的主导语言与项目术语由 Consumer 自己的 Repository Authority 决定。
