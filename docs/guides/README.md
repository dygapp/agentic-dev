# Guides — 人类使用文档

`docs/guides/` 只承担 **Human View**：帮助人理解、采用和维护 `agentic-dev`。ordinary Agent runtime 默认不依赖这里的文档；正式 Method、Rule、Skill contract 与 Architecture 以各自 canonical owner 为准。

推荐阅读：

1. [`using-agentic-dev.md`](using-agentic-dev.md) — 从整体上理解项目和日常使用方式；
2. [`adopting-agentic-dev.md`](adopting-agentic-dev.md) — 人类视角的 Consumer 首次采用指南；
3. [`upgrading-agentic-dev.md`](upgrading-agentic-dev.md) — 人类视角的 Existing Consumer 升级指南；
4. [`rule-activation-guide.md`](rule-activation-guide.md) — 理解 Rule Discovery 如何工作；
5. [`consumer-local-rule-activation.md`](consumer-local-rule-activation.md) — 理解 Rule 如何在 Consumer 本地化。

Guide 可以完整解释规范流程，但不重新定义 Gate、routing 或 policy。若 Guide 与 canonical owner 冲突，以 Method / Architecture / Skill / Rule 为准并修正 Guide。
