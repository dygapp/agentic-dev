# Project 目录导航

本 README 是 `agentic-dev` 自身 Project Knowledge 的 Human View。`docs/project/**` 描述这个 Repository 的使命、当前 capability instance、Roadmap 与稳定演进历史；它不是可直接传播给 Consumer 的 reusable capability。

当前长期 Project owners：

- [`project-charter.md`](project-charter.md) — 项目使命、问题、目标、非目标、核心项目需求与成功判据；
- [`project-capability-profile.md`](project-capability-profile.md) — 当前 Repository 如何实例化 Method / Skill / Rule Discovery / Human View 等 capability contract；
- [`project-roadmap.md`](project-roadmap.md) — 当前正式 baseline、当前 evolution / Gate、下一候选与持续观察事项；
- [`project-evolution.md`](project-evolution.md) — 对理解当前项目仍有价值的稳定演进里程碑摘要。

Project / Architecture 的长期边界由 `docs/architecture/project-knowledge-architecture.md` 定义。

精确 Open Issue / PR、branch、Action、commit 与 review 状态始终重新从 GitHub 当前事实读取；本目录不复制完整运行流水账。
