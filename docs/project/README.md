# Project 目录导航

`docs/project/**` 只描述 `agentic-dev` 这个 Repository 自身，不向普通 Consumer 传播。

长期 Project owners：

- [`project-charter.md`](project-charter.md) — 项目使命、产品边界、目标、非目标与成功判据；
- [`project-roadmap.md`](project-roadmap.md) — 当前 baseline、当前收敛阶段与下一责任；
- [`project-evolution.md`](project-evolution.md) — 对理解当前项目仍有价值的稳定演进历史。

本轮产品边界重构期间，`methodology-product-boundary-specification.md` 与 `methodology-product-boundary-implementation-plan.md` 继续作为临时 Current Authority；重构完成后按 Roadmap 退出 Current Authority。

精确 branch、HEAD、Issue / PR、Actions、review 与 merge 状态始终重新从 GitHub 当前事实读取，不在本目录复制运行流水账。
